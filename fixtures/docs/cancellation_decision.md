# DEMO-1: согласованное изменение отмены заказа
Синтетическое решение команды, не регламент Авито.
Область действия: только DEMO-1. Для других задач каналы нужно уточнять.
При OrderCancelled с reason=seller_cancelled отправлять покупателю email.
Использовать существующий шаблон order_cancelled и поле buyer_id.
Сохранить текущее уведомление payment_expired без изменения.
Остальные причины не должны отправлять уведомления.
Повторная доставка одного order_id + reason не должна отправлять второе письмо.
Защита от повторов должна быть в notification-service, а не в order-service.
Подготовить план изменения и тестирования; код автоматически не изменять.
