# DEMO-3: статус заказа после доставки
Синтетическая спецификация, не регламент Авито.
delivery-service публикует ShipmentDelivered, order-service принимает это событие.
Текущее поведение OnShipmentDelivered: записывает delivered_at, но не меняет статус.
Требование: перевести заказ shipped → delivered и сохранить delivered_at атомарно.
Заказ delivered при повторном событии не менять; событие подтвердить без ошибки.
Заказы cancelled игнорировать: поздняя доставка не должна отменять отмену заказа.
Событие для неизвестного order_id направлять в dead-letter, не создавать заказ.
Уведомления покупателю и изменение inventory-service в DEMO-3 не входят.
