# Записанные ответы настоящей модели

Ответы Qwen 3.8 Flash через Polza, полученные 14 ноября 2026 года
на синтетическом корпусе этого проекта. Это запись, а не новый анализ.
DEMO-4 сформирован локально без LLM, поскольку у профиля нет доступов.
`evaluation.json` содержит метрики итогового прогона, включая время и usage.

Показ без сети и без API-ключа:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/walkthrough.py --case DEMO-1 --replay examples/recorded/DEMO-1.json
```

Для остальных задач меняйте --case и имя файла; для DEMO-5/6 добавьте
`--profile reviewer`. После просмотра плана `--confirm-save` сохраняет ready-план
в локальной имитации Jira. Команда явно печатает `mode: replay`.

Проверка смысловой корректности остаётся необходимой. Например, согласованное
требование DEMO-1 не означает, что оно уже реализовано; формулировки модели
о прошлых изменениях нужно сверять с кодом. Эталонные проверки не доказывают
правильность каждого предложения и устойчивость к любым prompt injection.
